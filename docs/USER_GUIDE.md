## Getting Started

### Accessing the Website

Navigate to the website URL in your web browser. You'll see the public home page with information about Spanish lessons and pricing.

### Signing In

1. Click **Sign In** in the top navigation bar
2. Enter your email address and password
3. Click **Sign in**
4. You'll be redirected to your dashboard (Student or Admin based on your role)

## Student Guide

### Student Dashboard

After signing in, you'll see your personal dashboard with:

- **Upcoming Classes** - Your scheduled lessons
- **Package Credits** - Available prepaid class credits
- **Balance Due** - Any unpaid classes
- **Recent Documents** - Learning materials from Karen

### Booking a Class

1. Click **Book a Class** from your dashboard
2. **Step 1**: Select a time slot (e.g., "Mondays 10:00 AM - 11:00 AM")
3. **Step 2**: Choose an available date from the calendar
4. **Step 3**: Confirm and pay
   - If you have package credits, check "Use package credit"
   - Otherwise, you'll be redirected to Stripe for secure payment

### Using Package Credits

If you've purchased a class package:
- Your available credits appear on the booking page
- Check "Use package credit" when booking to use one credit
- Credits are automatically deducted when you book

### Purchasing Class Packages

1. From the booking page, you'll see available packages
2. Click on a package to purchase
3. Complete payment through Stripe
4. Credits are immediately available for booking

### Viewing Payment History

1. Click **Payment History** from your dashboard
2. View all past transactions
3. See your total paid amount and any outstanding balance

### Accessing Documents

1. Click **My Documents** from your dashboard
2. Click on any document to download
3. Documents may include lesson materials, homework, or resources

### Cancelling a Class

- From your dashboard, find the class under "Upcoming Classes"
- Click **Cancel** (available up to 24 hours before class time)
- If paid with a package credit, the credit is restored to your account

## Administrator Guide

### Admin Dashboard

The admin dashboard provides a business overview:

- **Active Students** - Total enrolled students
- **Today's Classes** - Lessons scheduled for today
- **Revenue This Month** - Monthly earnings
- **New Inquiries** - Unread contact form messages

### Quick Actions

From the dashboard, quickly access:
- **Add Student** - Create new student account
- **Add Time Slot** - Define availability
- **Upload Document** - Share learning materials
- **View Inquiries** - Read contact messages

### Managing Students

#### Creating a Student Account

1. Click **Add Student** or go to **Students** > **Add Student**
2. Enter student details:
   - First and Last Name
   - Email Address
   - Custom Hourly Rate (optional - leave blank for default)
   - Password
3. Click **Create Student Account**
4. Share login credentials with the student

#### Editing a Student

1. Go to **Students**
2. Click **Edit** next to the student
3. Update information as needed
4. Optionally set a custom hourly rate
5. Toggle **Active** status to enable/disable account
6. Click **Save Changes**

#### Custom Pricing

To set special pricing for a student:
1. Edit the student's account
2. Enter the **Custom Hourly Rate** (e.g., $20.00)
3. Save changes
4. This rate applies to all their future class bookings

### Managing Time Slots

#### Creating Recurring Time Slots

1. Go to **Time Slots** > **Add Time Slot**
2. Check **Recurring Weekly**
3. Select the **Day of Week**
4. Set **Start Time** and **End Time**
5. Ensure **Active** is checked
6. Click **Create Time Slot**

#### Creating One-Time Availability

1. Go to **Time Slots** > **Add Time Slot**
2. Uncheck **Recurring Weekly**
3. Select the **Specific Date**
4. Set times
5. Click **Create Time Slot**

#### Deactivating Time Slots

- From **Time Slots**, click **Deactivate** on any slot
- Deactivated slots won't appear for student booking
- Existing scheduled classes are not affected

### Viewing the Schedule

1. Go to **Schedule**
2. Filter by:
   - **Date Range** - Start and end dates
   - **Student** - Specific student's classes
3. For each class, you can:
   - **Complete** - Mark the class as finished
   - **Cancel** - Cancel the scheduled class

### Managing Payments

1. Go to **Payments**
2. View all transactions with filters:
   - **Date Range**
   - **Student**
3. See totals for:
   - **Total Revenue** (filtered results)
   - **Pending Payments**

### Managing Documents

#### Uploading Documents

1. Go to **Documents** > **Upload Document**
2. Enter a **Document Title**
3. Click **Choose File** to select the document
4. Choose distribution:
   - Check **Available to All Students** for global access
   - Or select specific students from the list
5. Click **Upload Document**

#### Assigning Documents to Students

1. Go to **Documents**
2. Click **Assign** next to any document
3. Check/uncheck students who should have access
4. Click **Save Assignments**

#### Deleting Documents

1. Go to **Documents**
2. Click **Delete** next to the document
3. Confirm deletion

### Handling Contact Inquiries

1. Go to **Inquiries** (or click the new inquiries notification)
2. Review each message with:
   - Contact name and email
   - Phone number (if provided)
   - Message content
   - Submission date
3. Take action:
   - **Mark as Responded** - After you've replied via email
   - **Close** - Archive the inquiry

### Managing Packages

1. Go to **Packages** (from Dashboard navigation)
2. View, edit, or create class packages
3. Set:
   - Package name
   - Description
   - Number of classes included
   - Price
   - Active status

## Tips & Best Practices

### For Students

- Book classes at least 24 hours in advance
- Purchase packages to save money on multiple lessons
- Download documents before your lessons to prepare
- Check your dashboard regularly for updates

### For Administrators

- Set up recurring time slots for your regular availability
- Use custom pricing for long-term students or special arrangements
- Upload lesson materials before class so students can prepare
- Check inquiries daily to respond to potential students promptly
- Review the payments section regularly to track outstanding balances

## Troubleshooting

### Can't Sign In

- Verify your email address is correct
- Check that Caps Lock is off
- Contact Karen if you've forgotten your password

### Payment Failed

- Verify your card details are correct
- Ensure sufficient funds are available
- Try a different payment method
- Contact Karen if issues persist

### Can't Book a Class

- Ensure you're signed in
- Check that the time slot hasn't already been booked
- Verify your account is active (contact Karen if unsure)

### Missing Documents

- Documents may be assigned to specific students only
- Contact Karen if you believe you should have access
